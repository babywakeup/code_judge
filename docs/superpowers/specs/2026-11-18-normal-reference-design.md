# 正常参考图输出

用户确认的范围：仅实施 periodic_template_matcher 输出优化，第 1 部分留待后续。
使用当前输入图与正常模板，将已验证的模板片段校正到输入图的亮度、对比度，
输出与输入图同坐标、同尺寸的 supposed_to_be_good.png 到既有结果目录。
保留 segmentation 行为，不使用缺陷矩形框，不在此阶段进行缺陷分割。

方案：每片段采用稳健线性光度校正（gain、offset），通过残差剔除异常像素，
过滤饱和像素及高梯度边缘。对比直接整体校正，逐片段校正能适应模板来源差异；
对比自由光照场，固定线性模型更不易吸收缺陷。采用前面讨论的逐片段方案。
灰度处理一个通道，彩色处理 BGR 三通道；透明度不参与拟合。

实现选择：记录直接配准、周期补全、多模板补全及独立实例实际使用的几何片段。
拼接使用确定的覆盖优先级，不跨结构混合纹理，避免人为模糊缺陷对比基准。
通过 source map 和每片段变换表保存来源。输出单独的几何有效 mask 与校正可信 mask，
不将无可靠参考的区域用输入图填充。欠约束拟合使用可靠全局校正回退并标记，
不存在可靠全局校正时保留模板原始值、标为低可信，不虚构可靠像素。
审查补充：每个基础片段先排除原始实例前景及插值边缘，避免局部移位后残留旧实例；
参考有效性要求双线性插值的所有源像素都在模板有效范围内。

限制：线性光度校正不能解决非刚性错位或任意非线性光照；参考图不保证缺陷轮廓精度。
