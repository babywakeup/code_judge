# 正常参考图驱动的通用异常显化

用户已确认开始实现讨论的第一部分。缺陷不限颜色和类型，暂不决定整体变色是否属于缺陷。
目标是为后续分割提供异常线索，不将候选视为精准缺陷轮廓，不接入外部分割模型。

采用独立 Python 模块 `reference_anomaly`，读取 matcher 原结果目录中的 input、正常参考图、
参考有效性及来源图；默认输出到结果目录的 anomaly 子目录。支持数组 API，灰度/BGR/BGRA。
仅依赖现有 NumPy/OpenCV，不读取 XML 标注、矩形框或目标真值，不修改输入与 matcher 结果。

方案比较：单阈值颜色差容易受错位影响；仅用位移容差会丢失细小异常。
采用已讨论的双分支：严格差异保留所有线索，小邻域容差用于优先级判断，不否决严格候选。
颜色（Lab 含双向亮度）、平滑后颜色及梯度结构为独立信号，经稳健背景统计与绝对下限标定，
通过 max 合成连续强度，避免要求不同缺陷同时触发所有信号。

实现选择：默认容差半径 2 原图像素，可配置；比较候选位移必须保持相同来源片段，
所有信号共享同一位移以避免逐通道随意匹配。无效参考不参与计算；接缝和无效区邻域保留
严格响应但标为低可信。高低双阈值生成严格候选与容差候选，候选不按面积直接删除。
整片变化不额外做光度校正；保留整体残差统计和 matcher 光度参数，说明已被前级校正吸收
的变化无法单凭当前参考图恢复。分数为相对响应强度，不是缺陷概率。

输出：float32 原始响应和严格/容差分数 NPZ，严格/容差热图、原图叠加图、候选 mask、
优先候选 mask、比较有效 mask、可信图、各独立信号图，JSON 保存阈值、参数与连通候选
面积/峰值点/置信信息，便于后续生成提示。候选列表最多 200 项，mask 与分数保留全部。

验证：明暗/异色/结构缺陷、整体变化、轻微错位、细小异常、无效区与接缝、无变化输入、
通道格式、文件读取与路径保护、重跑清理；实际 SD-1 输出及可视检查。
