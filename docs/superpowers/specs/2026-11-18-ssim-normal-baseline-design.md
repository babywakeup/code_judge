# 多尺度 SSIM 与正常模板基准试验

用户确认尝试此前提出的两个方向。保留原严格、容差、显著性分支，新增独立多窗口 SSIM
响应及显著性热图；使用归一化局部均值/方差/协方差计算，不跨来源接缝或无效区域统计。
窗口 5、11、21 原图像素分别保存，小窗口信号不会被大窗口平均掉；保存完整亮度、
对比度与结构 SSIM 的多窗口响应。称“多窗口 SSIM”，不冒充标准 MS-SSIM 下采样乘积算法。

正常基准仅由正常模板之间的可靠对应区域建立，不用缺陷输入残差学习该基准。
先验证实际模板的正常到正常配准；通过时只使用有效高度内、标注类别一致且身份可靠
的区域。无法验证的类别/区域标为基准缺失，不作为已知正常。正常模板光度可互相校正，
记录其吸收整体变化的限制。模型基于纹理组/语义类别的稳健残差统计，正常样本不足时
不输出可靠标定。后续比较单独输出正常标定分数、有效 mask 和对比图。

API 与 CLI 保持现有用法；正常模板基准需要显式 `--normal-config` 指向已有模板配置，
正常参考路径可访问性与保存覆盖保护都必须验证，不修改配置、模板或原 matcher 输出。
不引入新依赖、外部模型或缺陷标注；不将候选减少宣称为精度提升。

验证：一致图 SSIM 为 0 异常；小缺陷、局部断裂和多窗口响应；无效孔洞、来源接缝；
正常基准不使用缺陷输入且会拒绝错配；缺失正常模型/类别明确标记；文件导出与覆盖保护；
当前 SD-1 可视比较及回归测试。

首轮实际比较：直接 SSIM 和正常基准仍会抬高正常纹理，未优于旧显著性。
新增有上限的支持融合：旧显著性乘以 1..2 的新证据支持，零显著性保持零，
旧/新显著性并排使用共同 0..6 色阶，独立分支不替换原算法。
独立审查指出重复模板别名覆盖保护和超大整数来源 ID 的浮点精度问题，均以失败测试复现
后修复；前者保护所有原始配置条目，后者先将来源 ID 精确映射为紧凑整数编号，
再对紧凑编号进行窗口极值比较，避免大整数的浮点精度丢失。
额外测试覆盖窗口角落跨来源，以及未知语义不套用背景模型。

最终验证：28 项聚焦测试通过，完整回归 200 项通过；`git diff --check` 通过。
当前 SD-1 已用 `--normal-config` 重新生成所有试验图，正常模板两个配准方向均通过。
独立新分支正常纹理响应仍偏多，因此保留为辅助证据；未用缺陷真值评估，不宣称精度提升。
