# 检测框约束的异常图割试验

用户批准先试检测框 + 异常种子图割。输入仅为保存的 input/正常参考、异常分数、参考有效性
和外部检测 XML。GT_labelme 的轮廓文件不得在预测阶段读取，用于独立的事后评价。
先固定算法参数并保存预测，再读取 GT；不根据当前 GT 选种子、阈值、候选或分割参数。

实现：每个检测框带 10%（至少 16 像素）上下文，参考有效区域内从显著性高响应连通区域
选有限个前景种子，从框外可靠低响应选背景种子。框内其余区域保留待判定，低热度不直接
指定为背景。异常响应与种子学得的参考残差分布提供 unary，原输入图邻域提供平滑项，
求 s-t 最小割。检测框为软范围约束，输出触框/触 ROI 等不完整提示。
不以白色为先验，不填充或伪造未知参考，多个框独立处理再取 union。

使用已有 SciPy 稀疏最大流（本环境已安装）、NumPy、OpenCV；不安装新依赖。
预测 API 无 GT 参数；预测结果保存到 anomaly/box_segmentation，独立评价 CLI 读取已保存
预测和 GT，保存 Precision/Recall/IoU/Dice、GT 参考覆盖和可视对比。
可选 --config 只提取 target/box；GT_labelme 字段被忽略，不打开其文件。

验证：synthetic 宽松框、明暗/异色缺陷、空种子、边界/无效参考、多框和 XML 坐标，
最大流能量方向、预测不读取 GT、导出覆盖保护、GT 评价算术与图像匹配。
实际图预测后冻结，单次评价并如实报告，无 GT 驱动调参。
