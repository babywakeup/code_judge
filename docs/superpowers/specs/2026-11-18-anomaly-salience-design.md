# 异常显著性热图试验

用户确认尝试“纹理复杂度校准 + 错位降权”。新增实验分支，不替换原始严格/容差分数与候选。
按正常参考图平滑梯度的四分位分组，在可靠像素上估计各组严格残差中位数与 MAD，
突出高于常见残差的部分；组证据不足时使用全局稳健统计。按容差/严格分数比值连续降权，
最小保留 25%；接缝附近保留 50%。无效位置分数为 0，并保留显式有效 mask。

显著性分数不是缺陷概率。它刻意强调局部异常，可能压低大面积一致变化；原始分支保留。
新增显著性热图、叠加图、候选和并排对比图，NPZ 保存 float32 显著性分数及降权图，
JSON 保存纹理分组、背景尺度和参数。现有结构权重 1.5 保持。
